# Design system

Dark shadcn/ui on Tailwind. This is the Claude-artifacts reading experience in its dark palette: near-black canvas, quiet zinc surfaces, 1px borders, tight type, one accent at a time. Predictable over expressive.

Source of truth for tokens is `src/index.css` generated by `scripts/init-artifact.sh`. Do not override tokens per artifact.

## Type

- Tailwind `font-sans` system stack. No webfonts.
- Body: `text-sm leading-6` for dense UI, `text-base leading-7` for prose.
- H1: `text-3xl` to `text-4xl`, `font-semibold`, `tracking-tight`, `text-balance`.
- H2: `text-xl`, `font-semibold`, `tracking-tight`.
- H3: `text-base`, `font-medium`.
- Lede: `text-base text-muted-foreground`.
- Labels and metadata: `text-xs uppercase tracking-wider text-muted-foreground`.
- Numbers, IDs, paths, timestamps: `font-mono text-sm` and `tabular-nums` in tables.
- Prose measure: `max-w-[68ch]`. Do not center long text.

## Layout

- Page: `mx-auto w-full max-w-5xl px-6 py-10 md:py-14`.
- Sections: `border-t border-border py-10`. First section has no top border.
- Section heading row: index in `font-mono text-xs text-muted-foreground`, title beside it.
- Grids: 12-column, `gap-4` or `gap-6`. Cards span 4 or 6 columns on `md`.
- Mobile: single column. Never let a table force horizontal page scroll; wrap it.

Use one of four shapes:

1. **Document**: header, numbered sections, prose, cards, callouts. Plans, explainers, specs.
2. **Dashboard**: header, stat row, grid of cards, table. Status and metrics.
3. **Comparison**: header, decision callout, table, option cards. Choices.
4. **Walkthrough**: header, numbered steps, code blocks, accordions for depth. How-tos and reviews.

## Components

Use shadcn/ui. Do not hand-roll what ships in `@/components/ui`.

- `Card`: default container. `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`. Padding stays at `p-6`.
- `Badge`: metadata and status. `variant="secondary"` for neutral, `outline` for quiet. No colored badges except destructive.
- `Button`: primary action only. `variant="ghost"` or `outline` for secondary. Icon buttons need `aria-label`.
- `Table`: for comparisons and records. Right-align numeric columns with `text-right tabular-nums`. No zebra striping.
- `Tabs`: switch between views of the same data, not a table of contents.
- `Accordion`: optional depth. Never hide the conclusion.
- `Separator`: structural breaks inside a card, not section dividers.
- `Alert`: one consequence, max two sentences.
- `Progress`: only with a real, stated total.
- `Tooltip`: clarifies an icon, never carries required information.

Code blocks: `<pre className="overflow-x-auto rounded-lg border border-border bg-muted/40 p-4 font-mono text-sm leading-6">`. Keep lines under 90 characters.

Charts: inline SVG or CSS bars only. No chart library. Label axes, include units, use `text-muted-foreground` for axis text.

## Content rules

- Lead with the answer. First section is the conclusion, not background.
- One H2 per idea. If a section has two topics, split it.
- Specific headings: "Upload limits", not "Details".
- Concrete nouns and numbers. Cut "seamless", "robust", "unlock", "leverage", "journey".
- No sentence that could appear in any document.
- Numbers get units and sources.
- Use `font-mono` for every code, ID, path, and metric.

## Anti-slop

Do not ship:

- Gradients, glassmorphism, glow, or decorative blobs.
- Hero images or stock illustration.
- Emoji or colored icon clouds.
- Every card with a different accent color.
- More than one primary button per view.
- Animations beyond shadcn defaults and `transition-colors`.
- Shadow stacks. Use borders.
- Centered body text.

## Accessibility

- Body text uses `foreground` or `muted-foreground`; never lower contrast for style.
- Every interactive element has a visible focus ring and a real label.
- Use semantic elements: `header`, `main`, `section`, `table`, `ol`, `button`.
- Tables need `caption` or a preceding heading.
- Respect reduced motion. shadcn defaults already do.
